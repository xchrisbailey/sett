# Fork of gpui-kit-markdown-editor

- Upstream: https://github.com/wabzqem/gpui-kit-markdown-editor
- Base version: 0.2.0 (crates.io)
- License: Apache-2.0 (see `LICENSE-APACHE`)
- Package name `gpui-kit-markdown-editor` and lib name `markdown_editor` are unchanged.

Every patched spot is marked with a `FORK` comment. `tests/round_trip.rs` and `tests/fixtures/` cover what we rely on.

## Patches we carry

Each line is a candidate for upstreaming.

- **gpui-kit 0.9.1 build fix** (`direct.rs`): sets `task_marker: None` on `BlockNode::ListItem`. Without it the crate doesn't compile against gpui-kit ^0.9.1.
- **Final newline** (`import.rs`, `document.rs`, `serialize.rs`): an odd trailing line ending is kept as trivia (`EditorDocument::final_line_ending`) and no longer becomes an empty paragraph. Before, every save added a `\n`.
- **Wiki-links** (`markdown_source.rs`): `[[target]]`, `[[target|label]]` and `[[target#heading]]` are written unescaped, when their inner text needs no escaping. In table cells the `|` is still escaped. Before, they were saved as `\[\[…\]\]`, which breaks the link for other tools.
- **Soft line breaks** (`import.rs`, `serialize.rs`, `command.rs`, `state.rs`): gpui-kit's parser folds soft breaks into spaces. A parse-only inline plugin claims text nodes that contain line endings, and the importer turns each break into an `editor-soft-break` atom. The atom shows as a space and saves as the original line ending. The editor's own block copy and paste keeps the breaks, an inline copy writes them as spaces, and external pastes are unchanged. Before, hard-wrapped paragraphs, quotes and list items were joined into one line.
- **List markers** (`kind.rs`, `import.rs`, `serialize.rs`, `transaction.rs`, `command.rs`): `BlockKindData::List` records its bullet (`-` `*` `+`) or ordered delimiter (`.` `)`). Adjacent lists merge only when their markers match, because in Markdown they are separate lists. Before, every list was written with `-` or `1.`.
- **Callout markers** (`markdown_source.rs`): a `[!TYPE]` marker at the start of a paragraph is written unescaped (`> [!NOTE]`). Before, it was saved as `\[!NOTE\]`. The one exception is a top-level plain quote whose first line is just a Callout marker, which came from an escaped `\[!NOTE]`. That marker stays escaped (`serialize.rs`), so the quote doesn't become a Callout on the next load.
- **Callouts** (`kind.rs`, `import.rs`, `serialize.rs`, `command.rs`, `state.rs`, `direct.rs`): `BlockKindData::Blockquote` carries `callout: Option<Callout>` (public as `BlockKind::Blockquote { callout: Option<CalloutKind> }`). The importer makes a top-level quote a Callout when its first line is just `[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]` or `[!CAUTION]` (any case). The marker and its line break leave the text, and the marker is kept as written. It doesn't use gpui-kit's `block_surface`, whose `Surface` nodes import as `Unknown` and save as nothing. The serializer writes the marker line, then the contents straight after it (a blank `>` line only when the first block can't follow a paragraph line, such as a rule or a list whose first item is empty). `EditorCommand::SetCallout` and `InsertCallout` set and create them; `InsertCallout` is refused below the top level, where the Insert Menu hides its callout options. Before, a callout was a plain quote with the marker as text.
- **Drawing callouts** (`callout.rs`, `color.rs`, `element.rs`, `frame.rs`, `state.rs`, `kind.rs`, `direct.rs`, `lib.rs`, `assets/icons/`): a top-level Callout is drawn as a tinted box with a 3px coloured left edge and a header row (Lucide icon, type name, a muted chevron), its blocks rendered inside with `BlockNode::render`. Every child is rendered, so an empty callout keeps its caret line. The header is labelled "<Type> callout", and its bounds are recorded in `FrameLayout::callout_headers` each frame; `BlockEditorState::callout_header_at` hit-tests them. The header text is darkened (or lightened, on a dark page) until it reaches 4.5:1 on the tint. A quote that isn't top level draws as a plain quote. It doesn't use gpui-kit's `Surface` node, which draws nothing for an empty callout and can't tell callouts apart.
- **Table delimiter row** (`kind.rs`, `import.rs`, `serialize.rs`, `table.rs`): the source's delimiter row (`|------|`) is kept for as long as it still matches the columns and their alignment. Before, it was always rewritten to `| --- |`.
- **Insert Menu** (`insert_menu.rs`, `menu.rs`, `state.rs`, `element.rs`, `lib.rs`): typing `/` as the only character of a paragraph opens a filterable list of block types under it. ↑/↓ move the highlight, Enter or Tab picks, Esc closes. Picking removes the typed `/query` and runs the option's `EditorCommand` as one undo step. Esc, a click outside, a query with no match, deleting the `/` or moving the caret away close it and leave the text alone. Text being composed with an IME is left out of the query, so the list holds still until it is committed. Hosts replace the options (`InsertMenuOption`) with `with_insert_menu_options` (an empty list turns the menu off). `key_context` now builds its string, so the `insert_menu` context can combine with the others.
- **Callout type menu** (`callout_menu.rs`, `menu.rs`, `callout.rs`, `command.rs`, `state.rs`, `element.rs`, `assets/icons/check.svg`): a click on a Callout's header, or `cmd-alt-c` (`ctrl-alt-c` elsewhere) with the caret in one, opens a "Callout type" list under the header: the five types (coloured icon, name, ✓ on the current one), a divider, then "Plain quote". ↑/↓ move the highlight (wrapping), Enter or Tab picks, Esc or a click outside closes; the highlight starts on the current type. Picking retypes that quote as one undo step through `BlockEditorModel::retype_quote`, which `SetCallout` now also uses, so the caret never moves. Outside a callout the shortcut propagates; with the header scrolled out of view (or not yet drawn) it opens nothing. Any edit, caret move or blur closes it. The header is now a `Button` role with a tooltip naming the shortcut. It is not a tab stop: the editor owns a single focus, so the keyboard route is the shortcut (#19), an exception to `CODING_STANDARDS.md`'s rule that everything clickable is focusable and opens on Enter. Its keys sit in a `callout_menu` key context, registered last.
- **Link Picker** (`link_picker.rs`, `menu.rs`, `state.rs`, `element.rs`, `lib.rs`): typing `[[` in a text block, outside inline code and code blocks, opens a list of the host's `LinkCandidate`s (set with `set_link_candidates`) under the `[[`. The text after it filters by title or slug, ignoring case: title prefixes first, then other matches, most recently changed first within each. ↑/↓ move the highlight (wrapping, skipping rows with `reachable: false`), Enter or Tab or a click picks, Esc closes. Picking replaces the typed `[[query` with `[[slug]]` as one undo step and puts the caret after it. Esc, typing `]]`, a caret move past the query, a caret move before the `[[`, or blur close it and leave the text alone; text being composed with an IME is left out of the query. With no match it stays open and says "No matching Items". Its keys sit in a `link_picker` key context, registered last. Unfinished `[[query` text is saved escaped (`\[\[query`), like any other brackets that aren't a complete Link.
- **Custom menus** (`menu.rs`): both menus share one popover, option row and wrapping highlight. They are custom rather than gpui-kit's `PopupMenu` because focus has to stay in the editor (the caret, the Insert Menu's filtering and the menu keys all run through it), and a `PopupMenu` takes focus when it opens.
- **Our build only, not for upstream** (`Cargo.toml`, `tests/mod.rs`, `component.rs`, `state.rs`, `projection.rs`): the GPUI view tests are gated behind a `view-tests` feature, and the `gpui-kit/test-support` dev-dependency is dropped because it pulls in `gpui-fast`, whose pins don't resolve in our workspace. The crate uses the workspace `gpui-kit`, and upstream's `Cargo.lock` is removed.

## Known normalisations

A file using any of these is rewritten on its first save; after that, saves are stable.

- `__bold__` / `_italic_` → `**bold**` / `*italic*`. The delimiter would have to live on gpui-kit's `TextMark`.
- Hard breaks (two trailing spaces, `\` + newline) → `<br>` with the lines joined.
- `$` in text → `\$`. Escaping is decided per text run, but a math span can cross marks.
- Setext headings → ATX, and closing `##` are dropped.
- `~~~` fences → backticks; indented code → fenced code.
- Table cell padding → `| a | b |`. The delimiter row is kept, as above.
- A URL inside `( )` → `<url>`.
- A blank `>` line between a Callout's marker and its first paragraph, list, heading, code block or quote is dropped (`> [!NOTE]\n>\n> Body` → `> [!NOTE]\n> Body`).
- Trailing spaces before a soft break are dropped. CRLF line endings between blocks become LF.
- Unescaped `[[…]]` or `[!X]` text could become a link on reparse if a matching `[…]: url` definition exists. This is unlikely in practice.
